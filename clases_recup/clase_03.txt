Print()
→ La función print() en Python se utiliza para mostrar información en la 
pantalla, normalmente en la consola.
→Sintaxis básica:       print("Hola mundo") → Resultado: Hola mundo
→Podemos mostrar el contenido de una variable:
nombre = “Juan”
print(nombre)    → Resultado:  Juan
→ Mostrar texto y variables
nombre = “Juan"
edad = 30
print(f"Mi nombre es {nombre} y tengo {edad} años")
→ Resultado: Mi nombres es  Juan y tengo 30 años

Print()
→ Mostrar el resultado de una operación 
a = 10
b = 5
print(a + b)    Resultado:  15
print(a * b) Resultado:  50
print(10 + 5)  Resultado:  15
→Podemos pasar varios elementos separados por comas:
nombre = “Juan"
edad = 30
print("Nombre:", nombre, "Edad:", edad)
Resultado: Nombre: Juan Edad: 30
Python agrega automáticamente un espacio entre los elementos.
--- pagina 8 ---
Información Privada
Print()
→Podemos cambiar ese espacio que Python deja entre elementos
print("Python", "Java", "C#", sep=" - ")
Resultado: Python - Java - C#
→Por defecto, cada print() termina con un salto de línea:
print("Hola")
print("Mundo")
Resultado: Hola
Mundo
→Podemos cambiar este comportamiento utilizando end:
print("Hola", end=" ")
print("Mundo")
Resultado: Hola Mundo

Función input()
• La función print() envía datos a la consola, mientras que la función input() obtiene datos de la 
consola.
• La función input() viene con un parámetro opcional: la cadena de mensaje. Te permite escribir 
un mensaje antes de que el usuario ingrese algo, por ejemplo:
• Cuando la función input() es llamada o invocada, el flujo del programa se detiene, el símbolo del 
cursor se mantiene parpadeando (le está indicando al usuario que tome acción ya que la consola 
está en modo de entrada) hasta que el usuario haya ingresado un dato y/o haya presionado la tecla 
Enter.
