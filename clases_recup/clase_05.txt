Nombres de variables
Reglas para nombrar variables
-Pueden contener:
Letras (a-z, A-Z)  → nombre = "Lucas"
Números (0-9)     → edad2 = 30
Guion bajo (_)      → _total = 100    ó total_compra = 100
-NO pueden empezar con número
2edad = 30  → Error
edad2 = 30  → Correcto
-No pueden tener espacios :
mi nombre = "Juan"  → Error
mi_nombre = "Juan"  → Correcto

Información Privada
Ejercicio para entregar en el aula virtual
1. Construir un programa que calcule la edad de una persona(solo año)
2. Construir  un programa  que permita pedir dos números y mostrar la 
suma.
3. Pedir la base y la altura y calcular el área. El programa debe devolver 
el siguiente mensaje: “El área es …”
4. Pedir al usuario que ingrese su edad y devuelva los siguientes 
mendajes:
“Es mayor de edad” Si la  edad es >= 18
“Es menor de edad” Si la edad es < 18
5. El programa debe permitir ingresar un numero si eso numero en 
mayor a cero informar “Positivo” sino informar “Negativo”
6. Pedir dos números. Si el primero es mayor que el segundo, informar 
que el primero es mayor. En caso contrario, informar que el segundo 
es mayor.
7. Pedir el precio de un producto. Si el precio es mayor a $50.000, 
aplicar un 10% de descuento. Si no, no aplicar descuento. Mostrar el 
precio final.
8. Pedir un número e indicar si es par o impar. Para determinarlo, 
utilizar el operador %.
